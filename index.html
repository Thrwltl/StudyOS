Keep your study workspace safe and portable.

↗ Export your data

Download your subjects, chapters, tasks, exams, planned study sessions, focus sessions, and daily goal as a JSON backup file. Keep it somewhere safe so you can restore it later or move to another device.

Included in backupAll data

Subject lists and chapter completion, tasks, exam dates, planned study sessions, focus history, and your daily study target.

Your backup will be generated from the latest saved data.

↻ Restore a backup

Choose a StudyOS JSON backup file that you exported earlier. The file will be checked before anything changes.

No file selected

Select a valid StudyOS JSON backup to preview it here.

⚠️ Restoring replaces the current StudyOS data in this browser. Export a backup of your current data first if you may need it.

How it works

1. Export

Download a timestamped .json file before clearing browser data or changing devices.

2. Keep it safe

Store the file in a folder you can find later. StudyOS does not upload your data to a server.

3. Restore when needed

Choose the file and confirm the replacement. Your dashboard will refresh with the restored information.
